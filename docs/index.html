#99 [BUILD] (사용자 지시, 2026-09-04) 제작 방식을 "누르면 즉시 완성돼서 인벤토리에 바로 들어옴"에서 **"수량 지정 → 재료 선소모 → 타이머(1개당 5초) → 제작 공간에 결과물이 쌓임 → 플레이어가 직접 수령"** 방식으로 전면 개편한다. 가공대/제련로/조리대/조리용 화로 4개 전부에 적용한다(이미 `world.gd`의 `open_crafting_window()`/`_on_craft_pressed()`를 공통으로 쓰고 있으니 그 프레임워크를 고치면 4개 다 한 번에 적용됨). **주의: #98(인벤토리 꽉 찼을 때 아이템 소실 버그 수정)을 먼저 완료한 뒤 진행한다** — 이번 항목의 "수령" 단계가 그 안전한 패턴(공간 확인 후 이전, 부족하면 제작 공간에 그대로 둠)을 그대로 재사용해야 하기 때문이다. 구체 사양: (1) 제작 UI에 레시피별로 수량을 지정하는 입력(SpinBox 또는 +/- 버튼, 기본값 1)을 추가한다. (2) "제작 시작"을 누르면 지정한 수량 전체분의 재료가 있는지 확인하고, 있으면 **그 시점에 전량 한 번에 소모**한다(부족하면 시작 안 됨). (3) 그 뒤로 `CRAFT_SECONDS_PER_UNIT := 5.0`(1개당 5초 — **이 수치는 명시적으로 임시값이며 나중에 다 바뀔 예정이니 상수로 빼서 쉽게 찾을 수 있게 할 것**) 간격으로 결과물이 1개씩 생산되어, 인벤토리가 아니라 **그 제작대/화로 자체의 내부 출력 버퍼**(`{item, count}` 형태, 저장 상자와 비슷한 개념이지만 재사용 안 해도 됨 — 새로 만들어도 됨)에 쌓인다. 이 타이머는 `_process(delta)`로 실시간 진행되고, 플레이어가 UI를 닫거나 자리를 떠나도 계속 진행된다(다시 상호작용하면 진행 상황이 그대로 보임). (4) 제작 UI(또는 별도 "수령" 버튼)에 지금까지 쌓인 출력 버퍼 수량과 남은 시간/개수를 표시하고, 수령 버튼을 누르면 #98에서 만든 안전한 방식으로 플레이어 인벤토리에 옮긴다 — 공간이 부족하면 옮길 수 있는 만큼만 옮기고 나머지는 계속 제작대 출력 버퍼에 남아있는다(사라지지 않음). (5) 한 번에 한 배치만 진행 가능하면 충분하다(이미 배치가 진행 중이면 새 배치 시작 버튼을 비활성화 — 여러 배치 동시 진행/큐잉은 이번 범위 아님). (6) 나중에 NPC/자동화가 이 출력 버퍼에서 자동으로 상자에 옮기게 만들 계획이니, 출력 버퍼가 플레이어 UI 코드에만 강하게 묶여있지 않고 별도로 접근 가능한 구조면 좋다(엄격한 요구사항은 아님). UI 예쁘게 만드는 건 이번 범위가 아니다(기능만 되면 됨, 사용자가 명시적으로 "UI는 나중에" 언급함). 4개 제작대 중 최소 하나(가공대)로 수량 3개 정도 제작해서 5초 간격으로 하나씩 출력 버퍼에 쌓이는지, 수령이 정상 작동하는지, 인벤토리를 꽉 채운 채로 수령해도 아이템이 사라지지 않고 버퍼에 남는지 확인한다.
