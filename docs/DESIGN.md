## 무엇을

2D 탑다운 도트 그래픽 멀티플레이 게임. **힐링(생활: 채집/농사/목장)** 과 **PvP(총기 전투)**
두 축을 함께 가진다. 그래픽은 스타듀밸리 같은 도트 스타일. 전투 감각의 기준은 "덕코프".

## 범위 안

### 조작
- 이동: WASD
- 시야/조준 방향: 마우스로 회전
- 좌클릭: 발사(장전된 탄종으로 사격)
- 우클릭: 장전된 탄종 전환 (기본탄 ↔ 마취탄)

### 전투
- 총기 기반 전투. 총마다 세부는 다르지만 기본은 "조준선을 대상에 놓고 쏜다".
- 탄종: 기본탄, 마취탄 (그 외 탄종은 미정)
- **포획**: 대상 동물의 체력이 10% 미만으로 떨어진 상태에서 마취탄에 맞으면 포획할 수 있다.
- PvP 지원 (플레이어 대 플레이어 전투)

### 생활 스킬 — 채집 계열
- **사냥**: 총으로 동물을 공격해서 잡는다.
- **벌목**: 도끼.
- **채집 + 채광**: 삽(채집)과 곡괭이(채광)를 한 세트 도구로 묶어서 다룬다.
- **낚시**: 낚싯대. 다른 채집 대상은 필드 아무 데나 있지만, 낚시는 **바다의 "낚시 스팟"** 에서만 가능하다.

### 생활 스킬 — 생산 계열
- **농사**: 채집으로 얻은 씨앗을 심어서 진행한다.
- **목장**: 사냥 후 마취탄으로 포획한 동물을 사육한다.

### 동물 AI
- 평소에는 배회(랜덤 이동)한다.
- 플레이어가 가까이 다가가거나 총에 맞으면 도망간다.

### 시간 / 계절 / 날씨
- 낮/밤이 타이머로 정해져 있다 (구체적인 길이는 미정).
- 날짜: 1·2·3월 = 봄, 4·5·6월 = 여름, 7·8·9월 = 가을, 10·11·12월 = 겨울.
- 비는 낮에도 밤에도 올 수 있고, 각각 독립적으로 랜덤이다 (낮에만/밤에만/둘 다/둘 다 아님 전부 가능).
- **기본 강수 확률**: 하루 1%에서 시작해서, 하루가 지날 때마다 +1%p씩 누적 증가한다.
  (그대로 두면 확률이 계속 오르기만 하므로, 이 규칙은 일부러 아주 낮게 시작해서 비 오는 날이
  드물게 만들려는 의도다 — 확률을 매일 리셋할지 계속 누적할지는 아직 정해지지 않았으니
  INBOX로 지시가 오기 전까지는 "계속 누적"으로 구현하고 결정 자체를 STATUS.md에 남길 것.)
- **여름(4·5·6월)** 은 장마 때문에 기본 강수 확률이 **30%** 다 (위의 1%→누적 규칙 대신 30%를
  기준값으로 쓴다는 뜻; 30%에도 매일 +1%p가 붙는지는 미정 — 마찬가지로 결정하고 기록할 것).

### 멀티플레이
- 세션 서버 구조. 한 명이 세션 서버를 열면 다른 플레이어가 그 세션에 들어와 함께 플레이한다.
- 서버가 호스트 겸용인지 별도 전용 서버인지, 동시접속 인원 등 세부 아키텍처는 미정.

## 그래픽 파이프라인 (중요 규칙)

- **그림은 반드시 도구로 만든다. 손으로(코드로 직접 좌표를 찍어) 그리지 않는다.**
  근거: 손으로 그리면 외곽선이 뭉개지고 선이 떨려서, 다른 사람이 봤을 때 퀄리티가 바로 티가 난다.
- 도트 그래픽 생성 도구는 **PixelLab**(AI 모델)을 쓴다.
- API 키는 코드나 md 파일에 직접 적지 않는다. `loop/secrets.env`(git에 커밋되지 않음)에
  `PIXELLAB_API_KEY` 환경변수로 들어있고, `loop.sh`가 매 바퀴 세션을 열 때 이 환경변수를
  자동으로 물려준다 — 세션은 그냥 환경변수 `PIXELLAB_API_KEY`를 읽어서 쓰면 된다.
- PixelLab로 여러 결과를 생성한 뒤, 그중 괜찮은 것을 골라서 채택한다(생성 → 검수 → 채택).
  API 스펙(엔드포인트/파라미터)은 필요할 때 직접 조회해서 확인한다.

## 주요 결정과 이유

- 그래픽은 PixelLab AI 생성물만 쓰고 손으로 그리지 않기로 함. 근거: 위 "그래픽 파이프라인" 참고.
- 강수 확률은 낮게 시작해서(1%) 매일 누적 상승시키기로 함. 근거: 낮/밤 비 여부를 각각
  독립적으로 랜덤 처리하면 하루에 비가 올 확률 자체가 높아지므로, 기본값을 낮게 눌러야 함.
